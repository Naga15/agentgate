# CNCF Sandbox readiness

`agentgate` aims to mature into a project suitable for the
[CNCF Sandbox](https://github.com/cncf/sandbox). This document tracks
readiness against the published expectations, in the open. It is a working
checklist, not a claim of acceptance.

## Sandbox application expectations

| Expectation | Status | Notes |
|---|---|---|
| Clearly defined scope within the cloud native landscape | ✅ | Governance layer for AI agents acting on developer platforms / Kubernetes |
| Open source under an OSI-approved license | ✅ | Apache-2.0 |
| Public code repository | ✅ | github.com/Naga15/agentgate |
| `README` explaining purpose and value | ✅ | [README](./README.md) |
| `CONTRIBUTING` guide | ✅ | [CONTRIBUTING](./CONTRIBUTING.md) |
| `GOVERNANCE` document | ✅ | [GOVERNANCE](./GOVERNANCE.md) |
| `MAINTAINERS` / `OWNERS` listing | ✅ | [MAINTAINERS](./MAINTAINERS.md) |
| Adopt the CNCF Code of Conduct | ✅ | [CODE_OF_CONDUCT](./CODE_OF_CONDUCT.md) |
| DCO or CLA on contributions | ✅ | DCO (`git commit -s`), enforced in CI |
| Public roadmap | ✅ | [ROADMAP](./ROADMAP.md) |
| Security disclosure process | ✅ | [SECURITY](./SECURITY.md) |
| A neutral, descriptive project name | ✅ | "agentgate" (working name; trademark check pending before any application) |
| More than one independent maintainer / org | ⏳ | **Actively recruiting** — see CONTRIBUTING. Single maintainer today. |
| Demonstrated end-user or adopter interest | ⏳ | Pre-adoption; gathering early adopters |
| Healthy contribution activity | ⏳ | Early; kernel landed, adapters open for owners |

## What "done enough to apply" looks like

The honest gating items are the bottom three: **a second independent
maintainer, at least one named adopter, and a few months of real
contribution activity.** Everything structural (license, governance, CoC,
DCO, roadmap, security policy) is already in place so that those community
items are the only thing between here and a credible application.

If you'd like to help get there — as a co-maintainer, an adopter, or an
adapter owner — please see [CONTRIBUTING](./CONTRIBUTING.md).
