# Maintainers

This file lists the maintainers of the `agentgate` project. Maintainers have
write access and are responsible for reviews, releases, roadmap, and
governance (see [GOVERNANCE.md](./GOVERNANCE.md)).

| Name | GitHub | Role | Area |
|---|---|---|---|
| Naga15 | [@Naga15](https://github.com/Naga15) | Founder / Lead Maintainer | Core kernel, policy, governance |

## Becoming a maintainer

`agentgate` actively wants more maintainers. The path is intentionally
merit-based and documented in [GOVERNANCE.md](./GOVERNANCE.md#becoming-a-maintainer):
sustained, high-quality contribution (code, review, docs, or design
leadership) followed by nomination and lazy-consensus approval from the
existing maintainers.

If you're interested, the fastest start is to pick up a
[`good first issue`](https://github.com/Naga15/agentgate/labels/good%20first%20issue)
or propose a design in an issue. We're particularly looking for owners of
the adapter subprojects (MCP, Backstage, Kubernetes) listed in
[ROADMAP.md](./ROADMAP.md).
